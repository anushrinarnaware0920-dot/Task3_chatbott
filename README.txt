# 🤖 CodeBot – Basic Rule-Based Chatbot

## 📌 Project Overview

CodeBot is a simple **rule-based chatbot developed using Python** as part of the **CodeAlpha Python Programming Internship – Task 4**.

The chatbot interacts with users through the console and provides predefined responses to different user inputs.

This project demonstrates fundamental Python programming concepts such as **functions, conditional statements, loops, strings, lists, user input, and output**.

## 🎯 Objective

The objective of this project is to create a simple chatbot that can:

* Respond to common greetings
* Answer basic questions
* Provide information about Python
* Provide simple study tips
* Display the current date and time
* Perform basic mathematical calculations
* Store and display chat history
* Provide a help menu
* Exit the conversation when requested

## ✨ Features

### 👋 1. Greeting

The chatbot responds to greetings such as:

```text
hello
hi
hey
good morning
good evening
```

### 🤖 2. Chatbot Information

Users can ask:

```text
What is your name?
Who are you?
What can you do?
```

The chatbot provides predefined responses.

### 🐍 3. Python Information

The chatbot provides basic information about Python and its common applications, such as:

* Artificial Intelligence
* Machine Learning
* Web Development
* Data Science
* Automation

### 📚 4. Study and Exam Tips

The chatbot provides simple study suggestions when users ask about:

```text
study
exam
```

### 🕐 5. Date and Time

The chatbot can display the current:

* Date
* Time

This feature uses Python's built-in `datetime` module.

### 🧮 6. Simple Calculator

The chatbot can perform basic calculations.

Example:

```text
You: calculate 25 + 15

Bot: The answer is: 40
```

It supports basic mathematical operators such as:

```text
+
-
*
/
```

### 📜 7. Chat History

The chatbot stores messages during the current session.

Users can type:

```text
history
```

to view the previous conversation.

### ❓ 8. Help Command

Users can type:

```text
help
```

to display the available commands and questions.

### 👋 9. Exit Command

The conversation can be ended using:

```text
bye
exit
quit
```

## ⚙️ How to Run

### Step 1: Install Python

Make sure Python is installed on your computer.

Check the Python version:

```bash
python --version
```

### Step 2: Open the Project

Open the `Task4_BasicChatbot` folder in Visual Studio Code.

### Step 3: Open Terminal

In VS Code, select:

```text
Terminal → New Terminal
```

### Step 4: Run the Program

Enter:

```bash
python chatbot.py
```
